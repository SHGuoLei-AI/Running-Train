## 三铁律

1. 时刻表数据（llt_schedule.db）不可修改
2. 客里表数据（kl_new.db）不可修改
3. 经由表数据只能来自客里表，**绝对不允许用时刻表数据修正经由表**，反之亦然

## 经由设计流程

1. 从零匹配车次中找图内 OD（图内站 = 出现在 railway_track 中）
2. 查 kl 拓扑：线路车站、跨线接续、联络线
3. 计算累计里程（kl 精确值，不用圆整估算）
4. 与时刻表车次距离对比，偏差必须 = 0km（精确匹配）
5. 反复排查直到该 OD 所有车次全覆盖

## 匹配引擎

[`tools/match_trains.py`](tools/match_trains.py) — 对每趟车次的每对停站 (i, j)，检查距离是否落在某条经由上：

| 匹配类型 | 条件 |
|----------|------|
| 正向全匹配 | 起点=经由起点，终点=经由终点，距离差=0 |
| 反向全匹配 | 同上，方向相反 |
| 部分匹配（端点） | 一端=经由端点，另一端在经由上，距离差=0 |
| 部分匹配（中间段） | 两端都在经由中间，距离差=0 |
| 0km降级匹配 | 站名连续序列匹配（旅游列车等） |

支持车次类型过滤（禁止高速禁止普速），输出写入 `train_route_matches` 表。

## GUI 功能

### 主窗口
- 线路图绘制：区间渲染（黑色中线、红色上行、绿色下行）+ 站名标注
- 数据面板：线路表、区间表，表格编辑实时反映到画布
- 画布缩放：+/- 按钮调整显示比例，# 恢复默认
- 文件读写：打开/保存 JSON 格式运行图数据

### 经由编辑（工具 → 经由编辑）
- 经由列表：新增/删除/重命名经由，禁止高速/普速复选框
- 站序查看：按线路分段着色
- 头部/尾部延伸：基于 kl 数据双向延伸，支持跨线接续
- 头部/尾部删除：修剪经由端点
- **经由↔️车次匹配**：跑匹配引擎，实时进度+详细汇总（图外/0km/图内未匹配/图内未匹配区段分类）

### 工具菜单
- **经由匹配的车次**：左经由列表 → 右匹配车次，双击弹出车次详情
- **车次匹配的经由**：全部匹配结果一览，支持排序，可切换"只显示0匹配"，"图内未匹配区段"弹出明细
- **车次详情弹窗**：停站表 + 经由匹配段（灰色=未匹配）

│   ├── kl_new.db            # 客里表（里程来源，不可改）
│   ├── llt_schedule.db      # 时刻表（不可改）
│   ├── running_train.db     # 项目库（经由表、匹配表、railway_track）
