# 数据结构说明

## 文件一览

```
data/
├── kl.db             # 客里表 — 线路拓扑，变化不频繁（全局共用）
├── cc.db             # 时刻表 — 全国列车时刻，经常更新（全局共用）
├── rg.db             # 几何结构 — 当前激活图的铁路几何 + 经由
├── rt.db             # 图上车次 — 当前激活图的区域车次 + 匹配结果
├── rg-*.db / rt-*.db # 其他图的归档文件（如 rg-shanghai.db）
├── graphs.json       # 图配置 — 管理多图和 DB 路径映射
└── old/              # 旧文件归档（不入 git）
```

kl.db 和 cc.db 为全局数据源，所有图共用。rg.db 和 rt.db 为每图独立，
通过 `graphs.json` 和 `config.py` 实现多图切换。

## kl.db — 客里表

| 来源 | https://jprailfan.com/tools/stat/ |
|------|----------------------------------|
| 版本 | `meta.version` = 网站"数据更新:"后的8位日期 |
| 更新频率 | 几个月一次 |

### meta
| 列 | 类型 | 说明 |
|----|------|------|
| key | TEXT PK | 键名 |
| value | TEXT | 值 |

键名：`version`（8位日期，如 `20260501`）

### line_list — 线路列表
| 列 | 类型 | 说明 |
|----|------|------|
| id | INTEGER PK | |
| line_name | TEXT UNIQUE | 线路名 |
| start_station | TEXT | 起点站 |
| end_station | TEXT | 终点站 |
| mileage | INTEGER | 线路总里程 (km) |

### line_stations — 线路车站
| 列 | 类型 | 说明 |
|----|------|------|
| id | INTEGER PK | |
| line_name | TEXT | 线路名 |
| station_name | TEXT | 站名 |
| dist_from_start | INTEGER | 从线路起点的累计里程 (km) |
| dist_from_prev | INTEGER | 前一站到此站距离 (km) |
| is_junction | INTEGER | 是否枢纽站 (0/1) |

## rg.db — 几何结构

| 维护方式 | 基于客里表数据手工生成 |
|----------|------------------------|
| 版本 | `meta.version` 人工递增 |

### meta
| 列 | 类型 | 说明 |
|----|------|------|
| key | TEXT PK | 键名 |
| value | TEXT | 值 |

键名：
- `author` — 作者
- `version` — 几何结构版本号（人工递增）
- `kl_version` — 对应的客里表版本
- `cc_version` — 对应的时刻表版本

### train_graph — 图整体属性
| 列 | 类型 | 说明 |
|----|------|------|
| name | TEXT PK | 图名称 |
| length | INTEGER | 逻辑长度 (km) |
| width | INTEGER | 逻辑宽度 (km) |
| scale | INTEGER | 当前缩放比例 |
| default_scale | INTEGER | 默认缩放比例（# 按钮重置目标） |

### railway_path — 线路
| 列 | 类型 | 说明 |
|----|------|------|
| id | INTEGER PK | 自增 |
| graph_name | TEXT | 所属图 |
| code | TEXT | 短ID（如 NQX、HST） |
| name | TEXT | 显示名称 |
| kl_line_name | TEXT | 对应的客里表线路名 |
| start_x | INTEGER | 起点X坐标 |
| start_y | INTEGER | 起点Y坐标 |
| angle | INTEGER | 整体角度（度） |
| hidden | INTEGER | 是否隐藏 (0/1) |

### railway_track — 线路区段
| 列 | 类型 | 说明 |
|----|------|------|
| id | INTEGER PK | 自增 |
| path_id | INTEGER | 所属线路 (→ railway_path.id) |
| seq | INTEGER | 排序号 |
| head_station | TEXT | 头站 |
| tail_station | TEXT | 尾站 |
| length | INTEGER | 区段长度 |
| deflection | INTEGER | 偏转角（相对所属线路角度） |
| draw_head | INTEGER | 是否画头站名 (0/1) |
| draw_tail | INTEGER | 是否画尾站名 (0/1) |
| label_flip | INTEGER | 旧版标签反转标志（保留向后兼容，新代码不用） |
| up_direction | TEXT | 上行标签方向（N/E/S/W 四向，默认 N） |
| down_direction | TEXT | 下行标签方向（N/E/S/W 四向，默认 S） |

### routes — 经由
| 列 | 类型 | 说明 |
|----|------|------|
| id | INTEGER PK | 自增 |
| name | TEXT | 经由名称 |
| start_station | TEXT | 起点 |
| end_station | TEXT | 终点 |
| total_distance | INTEGER | 总里程 (km) |
| junction_count | INTEGER | 枢纽数 |
| prohibit_high_speed | INTEGER | 禁止高速车次 (0/1) |
| prohibit_normal_speed | INTEGER | 禁止普速车次 (0/1) |

### route_stations — 经由站序
| 列 | 类型 | 说明 |
|----|------|------|
| id | INTEGER PK | 自增 |
| route_id | INTEGER | 所属经由 (→ routes.id) |
| seq | INTEGER | 站序 |
| station_name | TEXT | 站名 |
| line_name | TEXT | 所在线路名（kl 线路） |
| cum_distance | INTEGER | 累计里程 (km) |
| is_junction | INTEGER | 是否枢纽站 (0/1) |

## rt.db — 图上车次

| 生成方式 | 从 cc.db 查找经停本图中任一车站的车次 |
|----------|--------------------------------------|
| 依赖 | cc.db + rg.db |

### meta
| 列 | 类型 | 说明 |
|----|------|------|
| key | TEXT PK | 键名 |
| value | TEXT | 值 |

键名：
- `cc_version` — 对应的时刻表版本
- `rg_version` — 对应的几何结构版本

### region_trains — 图内车次
| 列 | 类型 | 说明 |
|----|------|------|
| train_name | TEXT PK | 车次名 |
| from_station | TEXT | 始发站 |
| to_station | TEXT | 终到站 |

### train_stops — 图内车次停站
| 列 | 类型 | 说明 |
|----|------|------|
| train_name | TEXT | 车次名 |
| stop_seq | INTEGER | 停站序号 |
| station_name | TEXT | 站名 |
| arrive_time | TEXT | 到达时间 |
| depart_time | TEXT | 出发时间 |
| distance_km | INTEGER | 累计里程 |

> 只包含 region_trains 中车次的停站，从 cc.db 筛选得到。正常情况下可脱离 cc.db 使用。

### train_route_matches — 车次-经由匹配
| 列 | 类型 | 说明 |
|----|------|------|
| id | INTEGER PK | 自增 |
| train_name | TEXT | 车次名 |
| seg_start_seq | INTEGER | 区段起始站序 |
| seg_end_seq | INTEGER | 区段结束站序 |
| seg_start_station | TEXT | 区段起点站名 |
| seg_end_station | TEXT | 区段终点站名 |
| seg_distance_km | INTEGER | 区段里程 |
| route_id | INTEGER | 匹配的经由ID |
| route_name | TEXT | 匹配的经由名 |
| is_reverse | INTEGER | 是否反向 (0/1) |
| match_type | TEXT | 匹配类型（matched=已匹配 / unmatched=未匹配） |
| is_matched | INTEGER | 是否匹配 (1=已匹配 / 0=未匹配) |

## 数据流

```
kl.db (客里表) ──手工设计──→ rg.db (几何结构)
                                    │
cc.db (时刻表) ──筛选图内站──→ rt.db (区域车次 + 停站)
                                    │
rg.db + rt.db ──匹配引擎──→ rt.db (train_route_matches)
```

## 版本关联

```
rg.db.meta.kl_version  ←→  kl.db.meta.version
rg.db.meta.cc_version  ←→  cc.db.meta.version
rt.db.meta.rg_version  ←→  rg.db.meta.version
rt.db.meta.cc_version  ←→  cc.db.meta.version
```

匹配结果有效的前提：**rg.db 引用的 kl_version 和 cc_version 与当前 kl.db、cc.db 一致**。
